# YouTube OBS 多言語チャット

[简体中文](README.md) | [English](README.en.md) | **日本語**

公開中の YouTube ライブチャットを無料で取得し、API キー不要の Google 翻訳ウェブインターフェースで複数の言語に翻訳します。原文と翻訳を好きな順番に並べ、背景透過の OBS ブラウザソースに表示できます。チャンネル独自の絵文字、画像の絵文字、ステッカーにも対応しています。

**v0.5.0** で中国語・日本語・英語の UI に対応しました。チャットの無料取得と API キー不要の Google 翻訳も引き続き利用できます。Windows 版は [v0.5.0 Release](https://github.com/Miaowu-Mecci/Youtube-Chat-With-Translate/releases/tag/v0.5.0) からダウンロードできます。EXE、説明書とライセンスを含む ZIP、SHA-256 チェックサムを用意しています。EXE の実行に Python、Node.js、Git のインストールは不要です。

## UI の言語

メイン画面右上の **Language** で **简体中文 / 日本語 / English** を選択できます。ボタン、設定の説明、翻訳先の言語名、状態、エラー診断、通知、アクセシビリティ用ラベルが選択した言語に切り替わります。UI の翻訳はプログラムに同梱されており、Google 翻訳やネットワーク接続は使用しません。

初回はブラウザの言語設定のうち、最初に一致する対応言語を使用します。一致しない場合は中国語になります。手動で選んだ言語は現在のブラウザに保存され、再読み込みや次回の起動後も保持されます。ブラウザのストレージが無効でも、現在のページでは切り替え可能です。UI の言語とチャットの翻訳先は別の設定です。UI を切り替えても、配信設定や原文・翻訳済みの内容は変更されず、翻訳リクエストも送信しません。

同じブラウザで同一オリジンのプレビューや overlay を開いている場合、UI の言語がすぐに同期されます。ページの再読み込みやコメントの再表示は行いません。OBS のブラウザソースは独立したストレージを持つため、外部ブラウザの言語設定とは共有されません。UI の言語切り替えは v0.5.0 以降で利用できます。

## クイックスタート

### Windows EXE（推奨）

1. [v0.5.0 Release](https://github.com/Miaowu-Mecci/Youtube-Chat-With-Translate/releases/tag/v0.5.0) から `YouTubeOBSChat.exe`、または説明書とライセンスを含む ZIP をダウンロードします。ZIP は解凍してから実行してください。Python、Node.js、Git は不要です。
2. 古いプログラムを終了してから EXE をダブルクリックします。設定画面が自動で開きます。ターミナルのウィンドウは開いたままにしてください。`http://127.0.0.1:12450` に手動でアクセスすることもできます。
3. **デモを試す** を押すと、8 言語の固定訳と画像の絵文字をオフラインで確認できます。デモは YouTube や翻訳サービスに接続しません。
4. 配信中の YouTube 動画 URL、または 11 文字の動画 ID を貼り付け、**ライブチャットに接続** を押します。
5. 翻訳を有効にし、翻訳先の言語を追加・並べ替えて設定を保存します。**保存して翻訳をテスト** で、Google に接続できるか事前に確認できます。
6. OBS に **ブラウザ** ソースを追加し、URL を `http://127.0.0.1:12450/overlay` に設定します。推奨サイズは 480 × 720 です。

API キーの申請・入力や、接続モード・翻訳サービスの選択は不要です。言語の選択と並べ替え、表示設定、翻訳のオン・オフ、診断機能を利用できます。

### ソースコードから実行する場合

ソースコードから実行する場合のみ、Python 3.11 以降と Node.js 22 以降が必要です。インストール後はターミナルを開き直してください。Windows では `install.cmd` で依存関係のインストールとフロントエンドのビルドを行い、`start.cmd` を実行して `http://127.0.0.1:12450` を開きます。

Windows 以外の環境、または手動でインストールする場合：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cd frontend
npm ci
npm run build
cd ..
.venv/bin/python main.py --no-browser
```

プログラムはローカルのループバックアドレスのみで待ち受けます。ポートを変更する場合は `--port 12460` を指定してください。データフォルダーは `YTCHAT_DATA_DIR` で指定できます。既定では、ソースコード版は `data/`、Windows EXE は `%LOCALAPPDATA%\YouTubeOBSChat\` を使用します。起動時にライブチャットへ自動接続することはありません。

各 overlay（設定画面のプレビューを含む）は、開くか再読み込みすると **コメント表示を開始しました** と表示し、そのページが以後に受信した新しいコメントのみを表示します。保存済みのチャットは再表示しません。1 つのページを再読み込みしても、他のページの表示やライブ接続には影響しません。設定変更や再接続では既存の行を更新し、過去のコメントを再び流しません。切断中に蓄積したコメントも再表示しません。開始メッセージは表示ページの準備完了を示すもので、実際の配信への接続状態は設定画面で確認してください。

## ライブチャットの無料取得

`watch?v=…`、`youtu.be/…`、`youtube.com/live/…` などの動画 URL と、11 文字の動画 ID に対応しています。ウェブページから渡される継続トークンと取得間隔に従ってチャットを受信します。複数のプレビューや OBS ソースでも、YouTube への接続は 1 つを共有します。重複除去、継続トークンを使用した再接続、コメント削除、ユーザーの禁止イベントの処理に対応しています。

**ライブチャットに接続** を押した後に投稿されたコメントのみ取得します。接続を確立している間の新しいコメントも保持します。それ以前の履歴は表示せず、翻訳キューにも追加しません。自動再接続では今回の接続開始時点を維持し、手動で再接続すると開始時点を更新します。パソコンの時計を正しく同期してください。

対応しているのは、公開されている配信中の動画のチャットのみです。非公開配信、チャットのリプレイ、`liveChatId` の直接指定、チャンネルのホームページからのライブ自動検索、コメント送信には対応していません。非公式のウェブプロトコルを使用するため、ログイン・年齢制限、認証、同意画面、地域・ネットワーク制限、リクエスト制限、ページの変更などにより接続できない場合があります。

独立したチャットページに初期データがない場合、動画の視聴ページからの取得も試みます。エラーはプロキシ接続の失敗、ログイン・認証の要求、配信前・配信終了、解析失敗を区別します。解析エラーには HTTP ステータス、応答形式、初期マーカーやチャットトークンの有無が含まれます。Cookie やページ本文は含みません。

ブラウザではログインせずにチャットを見られるのにアプリが接続できない場合、同じプロキシ経路を使用しているか確認してください。YouTube の取得は httpx、Google 翻訳は curl_cffi/libcurl を使用し、それぞれが対応する `HTTPS_PROXY` / `HTTP_PROXY` 環境変数に従います。問題を報告する際は、画面に表示された診断メッセージ全体を添えてください。

## 多言語翻訳

簡体字中国語、繁体字中国語、英語、日本語、韓国語、スペイン語、フランス語、ドイツ語に対応し、同時に最大 8 言語を選択できます。言語カードのドラッグ、または ↑ ↓ で順番を変更できます。すべての言語を削除することもできます。保存するとプレビューとすべての OBS ページに反映されます。翻訳先が空の場合は原文のみを表示し、翻訳リクエストや翻訳行、プレースホルダーは作成しません。デモも同じ設定に従います。言語を追加して保存すると翻訳を再開できます。

翻訳行は内容のみを表示し、`zh-Hans`、`en`、`ja` などの言語コードは表示しません。例えば、中国語と英語を選択し、「你好」というコメントを受信した場合：

```text
XXX: 你好
  · 你好
  · Hello
```

原文はすぐに表示し、翻訳ができ次第、元のコメントの下に追加します。コメントの順序は変更しません。原文と同じ言語・同じ内容の翻訳でも 1 行表示します。言語の順番だけを変更した場合は完了済みの翻訳を再利用します。言語の追加・削除や翻訳のオン・オフでは古い処理を取り消して保持中のコメントを更新しますが、ライブチャットには再接続しません。

Google のウェブ翻訳はアカウントや API キーなしで利用できますが、非公式のインターフェースであり、固定の無料枠や安定稼働の保証はありません。同時リクエスト数は 1、リクエスト間隔は最低 1 秒、待機キューは最大 200 件、リクエストのタイムアウトは 5 秒です。同じ本文・翻訳先のリクエストはまとめて処理し、結果をキャッシュします。言語が多いほど待ち時間が長くなります。HTTP 429 では 60 秒待機し、3 回連続で制限された場合は翻訳を一時停止します。HTTP 403、認証の要求、応答形式の変更でも一時停止します。

失敗しても原文と成功済みの翻訳は保持します。**翻訳を再開** は、保持中のコメントのうち未完了の言語だけを再処理します。リクエスト制限の待機時間を短縮することはできません。**保存して翻訳をテスト** は選択した各言語を順番に確認します。YouTube への接続は不要で、チャット翻訳がオフでも実行できます。翻訳先がない場合、テストと再開のボタンは使用できません。

デモは 8 言語のローカル固定サンプルを使用し、外部サービスには接続しません。デモが成功しても、実際に Google や YouTube に接続できるとは限りません。実際の翻訳を有効にすると、コメントの文字部分を Google に送信します。

## 絵文字とステッカー

YouTube の画像の絵文字、チャンネル・メンバー独自の絵文字について、繰り返しや文字との混在を含めて元の順序を維持します。有料コメント内の絵文字や Super Sticker の画像にも対応しています。支払金額やギフト・メンバーシップのカードは再現しません。Unicode の絵文字は通常どおり表示します。

画像の絵文字は文字サイズに合わせて拡大・縮小し、ステッカーのサイズには上限を設けています。画像の期限切れや読み込み失敗時は、名前・説明のテキストを表示します。翻訳対象は文字のみで、画像 URL や絵文字の名前は送信しません。画像だけのコメントでは翻訳処理を作成せず、言語ごとの「スキップ済み」も表示しません。画像の読み込み後にチャットのレイアウトを再計算します。

コメントに含まれる HTTPS の YouTube / Google 画像 CDN URL のみを使用します。任意の画像リンクを自動展開する機能や、アップロード、OCR、画像翻訳はありません。主なドメインは `*.ggpht.com`、`*.googleusercontent.com`、`*.gstatic.com`、`*.ytimg.com` です。デモの最初のコメントは、ネットワーク接続不要のローカルの花の画像を使用します。

## 表示設定と設定ファイル

文字サイズ、原文・翻訳の色、アイコン表示、保持するコメント数を変更し、プレビューで確認できます。保存すると OBS に反映されます。翻訳文には `.translation`、原文には `#message` を使用します。セレクターの例：

```css
yt-live-chat-renderer { background: transparent; }
yt-live-chat-text-message-renderer { padding: 10px 16px; }
yt-live-chat-author-chip #author-name { font-weight: bold; }
.translation { color: #8de1cb; font-weight: 600; }
```

通常の CSS で既定の CSS レイヤーを上書きできます。OBS のカスタム CSS もブラウザ標準のカスケード規則に従います。`@layer` と `:has()` に対応した新しい OBS ブラウザソースが必要です。

設定はデータフォルダーの `config.json` に保存します。旧設定の読み込み時は、廃止済みの接続モード、キー、サービス、リージョンを無視し、ライブ URL、対応する翻訳先、言語の順番、表示設定を維持します。次に保存した際に旧項目を削除します。非対応の旧言語は除外し、空でなかった旧リストからすべての言語が除外された場合は簡体字中国語に戻します。ユーザーが明示的に保存した空リストは、そのまま原文のみの設定として保持します。

チャット履歴はメモリ内のみで保持し、再起動すると消去されます。コメントは最大 500 件、重複除去用 ID と削除用 ID はそれぞれ最大 10,000 件保持します。YouTube の削除イベントが即時に配信されない場合があるため、リアルタイムの削除同期は保証できません。

## 開発とビルド

```sh
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
cd frontend
npm run build
npx playwright install chromium
npm test
```

ブラウザテストは独立した一時データフォルダーとローカルサーバーを使用し、ユーザーの設定を読み込まず、外部への翻訳リクエストも送信しません。gRPC / protobuf のインストールやコード生成は不要です。検証記録は [VALIDATION.md](VALIDATION.md)（中国語）を参照してください。

Windows 上で `build-exe.cmd` を実行すると、`dist/YouTubeOBSChat.exe` をビルドし、実際の起動を確認するスモークテストを行います。Windows EXE は Windows でビルドしてください。Linux からこの Windows EXE を直接生成することはできません。パッケージにはフロントエンド、オフライン画像サンプル、説明書、ライセンスを含み、ユーザーデータは含みません。

リリースタグや GitHub Release は、ユーザーが明示的に公開を依頼した場合のみ作成します。通常のソース変更、コミット、プッシュでは公開しません。

## ローカル API

| エンドポイント | 用途 |
| --- | --- |
| `GET /api/config`、`PUT /api/config` | 設定の取得・保存 |
| `POST /api/connect`、`POST /api/disconnect` | ライブチャットの接続・停止 |
| `POST /api/demo` | オフラインデモの開始 |
| `GET /api/status` | 接続状態と翻訳の進捗 |
| `GET /api/languages` | Google 翻訳の 8 言語の一覧 |
| `POST /api/translation/test` | 選択したすべての言語の翻訳テスト |
| `POST /api/translation/resume` | 未完了の翻訳の再開 |
| `WS /ws` | スナップショット、原文、翻訳、削除、状態のイベント |

コメントの `content_parts` は、文字・絵文字・ステッカーを順番に並べたデータです。`translations` は表示順を維持した言語ごとの翻訳結果です。言語コードはデータと HTML 属性に保持しますが、翻訳文の前には表示しません。
